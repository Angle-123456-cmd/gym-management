# 健身房管理系统 gym-management
## 项目介绍
基于Java + SpringBoot + MyBatis开发的健身房管理系统。
系统分为**会员端、管理员端两套登录角色**，不同角色拥有独立权限。
会员登录后可以查看课程、预约课程/教练、办理会员卡、查看个人资料、查看缴费与充值记录；管理员负责后台全部业务数据维护。

## 技术栈
- 后端：Java 、SpringBoot、MyBatis
- 数据库：MySQL
- 构建工具：Maven

## 功能模块
### 会员端
- 会员登录
- 查看课程信息
- 预约教练、预约课程
- 会员卡办理
- 查看个人资料
- 查看缴费、充值记录

### 管理员端
- 员工信息管理
- 会员信息管理
- 课程信息管理
- 健身房器材登记管理
- 会员缴费、充值记录管理

## 项目运行
1. 导入IDEA，Maven自动下载依赖
2. 修改application.yml中的MySQL数据库连接
3. 启动主类，访问项目
